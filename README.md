# Java_Print_Statements
Print statements in java 3 statements 1.printf 2.print 3.println and also err

In Java, the most common way to print text to the screen is by using the System.out.println() statement
CommandWhat it doesExample OutputSystem.out.println()Prints the text and moves to a new line.Prints text on separate lines.System.out.print()Prints the text but stays on the same line.Prints text side-by-side.System.out.printf()Prints formatted text using special placeholders.Useful for rounding decimals or aligning text.

How to Use Each Print Statement1. System.out.println() (Print Line)This is the standard print statement. Every time you use it, the computer prints your message and then skips down to the next line.
